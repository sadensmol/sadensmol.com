Welcome to my new blog! This is the first post, written to test things out.

## Why a Blog?

I wanted a simple place to write about things I'm working on and learning.

## Tech Stack

This site is built with:

- **Hugo** — a fast static site generator
- **GitHub Pages** — free static hosting
- **GitHub Actions** — automated builds and deploys

### How It Works

Every push to `main` triggers a build. Hugo compiles markdown into HTML, and GitHub Pages serves the result.
